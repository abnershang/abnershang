# Abner Shang

I work across business, data, and software. I build tools and workflows to solve problems I run into in real work.

Lately, I’ve been exploring how AI agents fit into that work: keeping context useful, making handoffs clearer, and checking what actually got done.

## Things I Build & Improve

### [OpenClaw](https://github.com/openclaw/openclaw)

Contributor. Reliability fixes across backups, updates, and Codex integration.

[Backup reliability](https://github.com/openclaw/openclaw/pull/72251) · [Restart handling](https://github.com/openclaw/openclaw/pull/105544) · [Codex continuation](https://github.com/openclaw/openclaw/pull/88321)

### [ZenMux Manager for Raycast](https://github.com/raycast/extensions/tree/main/extensions/zenmux-manager)

A Raycast extension for checking ZenMux usage and accessing its models.

### [PDF QR extraction](https://github.com/abnershang/get_qr_code_from_pdf)

A utility that extracts QR data from PDFs into CSV, retaining the source file and page for tracing results back.

## How I work

- Make assumptions explicit and keep data traceable.
- Leave enough context for someone else to continue the work.
- Keep the tooling simple.
